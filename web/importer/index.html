Local importer

This page decodes a file in the browser. It does not upload, sign in, or call a device.

The tested decoder is the C functions fz_import_rom and fz_import_wav_cycle. This page repeats those rules for audition and WAV export.

  • FZTEST — exactly 1024 bytes, four sounds of 256 unsigned 8-bit frames, 8000 Hz, roots 36–39. Each sample is (byte − 128) << 8.
  • WAV cycle — PCM, 8- or 16-bit, mono or stereo. The point count is the cycle. The file rate is shown and is not a root note.
  • Any other raw length is refused. No layout is guessed. Commercial ROMs are not built in.
