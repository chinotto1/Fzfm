Controls and what this simulator verifies

The display, input handling, samples, synthesis, sequencer, mixer and effects are the actual portable C application. Sound is rendered at 36,000 frames per second. This panel uses SCL as the logical SEL button; SELECT remains a rotary control. Use knob 1 to choose a list row, knobs 2–4 to edit the fields shown on the display, and SCL to apply.

SEQUENCE cycles steps, patterns and song. ARP opens actions including pattern copy/paste, ordered chains, take timing and pattern settings. SAVE queues while playing and commits when stopped. On the public emulator, SAVE stores this project in this browser on your iPad and restores it when you return. Export important projects to Files as a backup; clearing browser data removes local saves. Samples and audio stay on your device and are never uploaded.

Test hits simulate a host source. Actual iPad USB, codec timing, flash persistence and physical recovery still require device qualification. This is a development simulator, not an installable firmware release.
